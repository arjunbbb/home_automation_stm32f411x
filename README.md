# home_automation_stm32f411x
The Home Automation Using STM32F411 is a smart-home project designed to control and monitor electrical appliances automatically using a microcontroller. The STM32F411 acts as the main control unit and processes inputs from sensors or user commands to operate devices such as lights, fans, and other electrical appliances.

The system can use relays to switch appliances ON and OFF safely. Sensors can be integrated to detect conditions such as motion, temperature, light intensity, or room occupancy. Based on the sensor information, the STM32F411 can automatically control connected appliances. For example, lights can be switched ON when motion is detected, or appliances can be controlled according to the surrounding conditions.

The system can also be extended with a Bluetooth, Wi-Fi, or IoT communication module, allowing users to control appliances remotely through a smartphone or web interface. This provides convenience while also helping reduce unnecessary energy consumption.

The proposed system is cost-effective, reliable, and energy-efficient and can be used in homes, offices, classrooms, and other buildings.

Main Components
STM32F411 – Main microcontroller
Relay Module – Controls electrical appliances
PIR Sensor – Detects human movement
LDR Sensor – Detects light intensity
Temperature Sensor – Monitors room temperature
Wi-Fi/Bluetooth Module – Enables remote control
LEDs/Fan/Loads – Controlled electrical appliances
Working Principle

Sensors/User Command → STM32F411 → Processing → Relay Control → Electrical Appliance

The STM32F411 continuously monitors sensor inputs and user commands. According to the programmed conditions, it activates or deactivates the appropriate relay, thereby controlling the connected home appliances.
